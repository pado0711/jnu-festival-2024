## 서비스 소개

✅ 축제 관련 전반적인 정보 “한 눈에” “체계적으로” 확인 가능

✅ 사용자 개인화된 선별적 정보 관리 및 실시간 부스 트렌드 파악 가능 

✅ 축제 관련 커뮤니티 형성 

✅ 축제 및 대학에 대한 애착 형성 

✅ 대학 생활의 중요한 순간 기록 및 추억 아카이브
